# RezeBot — Telegram Super Bot Platform

[![Build Status](https://img.shields.io/badge/build-passing-brightgreen.svg)](https://github.com/rezebot/rezebot)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Node Version](https://img.shields.io/badge/node-20%2B-brightgreen.svg)](https://nodejs.org/)
[![TypeScript](https://img.shields.io/badge/typescript-5.5-blue.svg)](https://www.typescriptlang.org/)

**RezeBot** is a production-ready, modular **Telegram Super Bot Platform** supporting Persian (Farsi) Natural Language, AI Assistant, Security, Moderation, Web Panel, Mini App, Multi-Group Management, Crypto/Currency, Games, Economy, and more — all in a single extensible architecture.
